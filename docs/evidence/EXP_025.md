# EXP-025 promotion-release robustness rescue

Status: rejected. No production change.

## Question

Can the adaptive slate safely stop withholding candidates when category-bound promotion cannot supply a useful unseen candidate?

The mechanism is catalog-derived: it uses only whether the production promotion bucket exists and has an unseen member. It does not inspect product identifiers, public labels, perturbation names, or simulator phrases.

## Arms

Both arms use the selected primary at commit `3c452471ac2dc614eace54309e65ef78f3fb04d5`, the pinned official evaluator, seed 0, network disabled, and the schema-v6 catalog asset.

1. **release unresolved after turn one:** emit the full sparse slate when promotion has no unseen candidate, including when no bucket resolved;
2. **release only exhausted promotion:** emit the full sparse slate only when a non-empty promotion bucket has been completely emitted.

## Results

The broad arm regressed clean TechnicalScore from 0.978500 to 0.975800. HR@10 remained 1.000000 and MTTC improved from 2.025 to 2.010, but MRR fell from 0.996667 to 0.986667. The loss was isolated to intent-override sessions: after an override, ordered-prefix promotion is intentionally disabled, so treating an unresolved bucket as permission to emit ten products banked the target below rank one.

The exhausted-only arm was exactly neutral on the released set: TechnicalScore 0.978500, HR@10 1.000000, MRR 0.996667, and MTTC 2.025. It was then run over the seven failing registered slices. Every aggregate and every target-removal rate matched the selected primary:

| slice | target-removal rate |
|---|---:|
| filler | 0.005000 |
| paraphrase | 0.010000 |
| typo | 0.010000 |
| word order | 0.012658 |
| negation | 0.006410 |
| attribute swap | 0.040000 |
| constraint drop | 0.035000 |

## Decision

Reject both arms. The broad rule damages rank quality because “unresolved” has different semantics after intent revision. The narrow rule adds a configuration surface but changes no measured session, so it does not earn production complexity. The remaining robustness failures require better evidence recovery or ranking, not another emission-state flag.
