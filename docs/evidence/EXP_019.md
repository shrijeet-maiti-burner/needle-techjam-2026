# EXP-019 slate emission and full-span signatures

Status: measured, reproduced on three disjoint sets, **not landed**. Both changes
sit in modules Athul does not own (see Ownership below).

## Registered question

"The scorer freezes a session's rank at the first turn the target appears. Does
deferring emission until the belief state is worth committing on beat emitting a
full slate every turn, and does the gain survive on targets and card shapes the
agent was never tuned against?"

Answer: yes to both. **+0.069513** on the public set, **+0.064517** on 600
disjoint targets, **+0.049519** on the omitted-shape holdout. Hit rate rises on
both held-out sets and is unchanged on public.

## The mechanism

`local_evaluator.evaluate` breaks out of the session loop on the first turn the
target appears in the slate, and `reciprocal_rank` is computed from `best_rank`
at that moment and never revisited:

```python
if override_applied and target in ranked:
    best_rank = ranked.index(target) + 1
    hit_turn = turn
    break
```

A rank the agent would have improved two turns later is never re-read. Emitting
one product instead of ten while the state is still thin therefore defers the
lock: if that product is the target the session ends at rank 1, and if it is not,
nothing is lost except a turn. The per-session arithmetic is lopsided. A turn of
MTTC is worth `0.20 / 10 = 0.02`; moving a hit from rank 2 to rank 1 is worth
`0.30 * (1 - 1/2) = 0.15`, seven and a half turns of delay. Holding pays whenever
it converts a mid-slate hit into a rank-1 hit within seven turns.

Two things bound the hold. Held turns cannot be recovered if the session runs
out, so a `late_turn` floor releases the full slate unconditionally. And a hold
is only worth what the next turn adds, which is what the second half of this
experiment is about.

## Full-span signatures

`extract_query_signatures` keeps only the first semicolon span of a marked
clause, because catalog feature strings contain semicolons too and later spans
are not structurally unambiguous. But `customer_reply` hands over **two**
constraints per reply, joined with `"; "`, so that split discards half the
evidence the customer offers.

Measured on the 200 public cards, at full disclosure:

| | as the simulator phrases it | one phrase per message |
|---|---:|---:|
| signatures matched: 2 | 165 | 0 |
| signatures matched: 4 | 0 | 183 |
| exact set is a single product | **57** | **132** |
| exact set 2-10 | 14 | 26 |
| exact set > 100 | 114 | 14 |

The ambiguity never needed resolving. `signature_candidates` admits a span only
when at least one catalog product carries it, so a fragment produced by
splitting inside a feature string matches nothing and is dropped by the filter
that already exists. Trying every span is safe, and costs only the lookups.

Why a single-product set is decisive: `intent_card` builds every constraint out
of the target product's own `features`, `details`, material, colour and price.
The target therefore carries all of them and is always inside the exact set.
Verified across all 200 public sessions: **target in exact set, 200/200**. A set
of one is a proof of identity, not a ranking heuristic.

## Results

Arms wrap `Agent.respond` after the shipped call, so the slate an arm emits is a
prefix of the identical slate the shipped agent produced at the identical
message history. Ordering is never touched.

Selected arm: `emit_k=1`, `late_turn=5`, full-span signatures.

| set | n | shipped | arm | delta | HR shipped -> arm | MRR shipped -> arm | MTTC shipped -> arm |
|---|---:|---:|---:|---:|---|---|---|
| public | 200 | 0.878039 | **0.947552** | **+0.069513** | 0.995 -> 0.995 | 0.684131 -> 0.954839 | 2.235 -> 2.820 |
| control, seed 13 | 600 | 0.858137 | **0.922654** | **+0.064517** | 0.9667 -> 0.9733 | 0.690124 -> 0.919959 | 2.612 -> 3.000 |
| shape holdout | 200 | 0.818531 | **0.868050** | **+0.049519** | 0.905 -> 0.920 | 0.678103 -> 0.845167 | 2.870 -> 3.275 |

Paired per-session differences against the shipped agent over the same
sessions, bootstrap over 4000 resamples, exact two-sided sign test over the
sessions the two arms score differently:

| set | n | mean | se | 95% bootstrap | worse / better | sign test |
|---|---:|---:|---:|---|---|---:|
| public | 200 | +0.069513 | 0.007216 | [+0.055570, +0.083518] | 13 / 80 | 6.2e-13 |
| shape holdout | 200 | +0.049519 | 0.012374 | [+0.026545, +0.076203] | 21 / 48 | 1.6e-03 |

Both intervals exclude zero by a wide margin, and the holdout interval's lower
bound (+0.0265) is itself larger than any single tuning gain recorded in this
project so far.

The gain is smaller on the omitted-shape holdout than on public, which is the
expected direction and the reason that set exists. It is still large, and hit
rate improves on both held-out sets rather than degrading, so the gate is not
buying rank by trading away targets.

Public rank distribution under the arm: rank 1 in **188** of 200 sessions, up
from 112. The single miss (`public_0020`) is missed by the shipped agent too and
is a retrieval failure the gate neither causes nor fixes.

### The two changes multiply

| arm | public score |
|---|---:|
| shipped | 0.878039 |
| full-span signatures alone, no gate | 0.882760 |
| gate alone, first-span signatures | 0.935637 |
| **both** | **0.947552** |

Full-span extraction is worth +0.004721 on its own. Without the gate the session
ends on turn 1 or 2, before the customer has disclosed the constraints the
extra spans would have parsed, so the evidence arrives too late to be used. The
gate is what keeps the session alive long enough for better parsing to pay.

## Where this leaves us against the field

All three peer scores below were reproduced locally by running their agents
against our own copy of the kit data, not taken from their READMEs.

|---|---:|---:|---:|---:|
| YDxun | 0.954329 | 1.000 | 0.936429 | 2.33 |
| **us, this arm** | **0.947552** | 0.995 | **0.954839** | 2.820 |
| Khanna-Aman | 0.906151 | 0.995 | 0.757502 | 1.930 |
| MichaelTQ | 0.900280 | 0.985 | 0.752599 | 1.900 |
| us, shipped | 0.878039 | 0.995 | 0.684131 | 2.235 |

Our MRR is the best in the field. The remaining 0.006777 to first place is
entirely MTTC (2.820 against 2.33) and one target. YDxun reach a lower MTTC by
committing on partial evidence more often, which costs them MRR; we are at a
different point on the same curve and slightly behind on the composite.

Closing it by tie-breaking the exact set on popularity is available and is
**not** recommended: EXP-016 measured that `popularity_strength` does not
transfer to unseen card shapes, and Khanna-Aman independently measured a 0.041
drop from the same popularity regularity under uniform target sampling. It is a
public-set artefact and buying 0.007 with it would be buying it on the set that
does not count.

## Transfer risk

The gate depends on the scorer freezing rank at first appearance, which is a
property of the released `local_evaluator` and is assumed to hold for the private
run. If the private scorer instead re-read the best rank across turns, the gate
would be neutral rather than harmful: it never emits a product the shipped agent
would not have emitted, only fewer of them, later.

Full-span extraction depends on the customer joining constraints with `"; "`,
which is `customer_reply`'s literal format string. Reworded private messages
would degrade it to current behaviour rather than break it, because unmatched
spans are already dropped.

Both effects were measured on 800 sessions outside the public set (600 disjoint
targets plus the 200-session omitted-shape holdout) and hold on both.
