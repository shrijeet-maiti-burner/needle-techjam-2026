# EXP-024 catalog-only target-propensity prior

Status: rejected; no production change.

## Registered question and gate

Can a low-capacity model over participant-visible catalog metadata rank the
target above raw `rating_number` in underdetermined turn-one promotion buckets?

The arm was required to gain at least `+0.003` out-of-fold TechnicalScore,
preserve HR@10, and avoid regression on every previously registered matched,
target-disjoint panel. Private-label reconstruction, product identifiers, text
tokens, and product-specific lookup values were prohibited.

## Method

`scripts/target_propensity.py` fits deterministic pairwise logistic regression
against the exact catalog bucket faced by each turn-one decision. Half of each
negative set is the popularity head of the bucket and half is a stable coverage
sample. The feature allowlist is:

- log rating count and average rating;
- price presence and log price;
- first-available year and date presence;
- feature/detail counts;
- title/description lengths;
- category depth and store frequency.

No feature contains an ASIN, title/store/category token, brand, constraint text,
session identifier, or user profile. The public result is five-fold out of
fold: each session is evaluated by coefficients fitted without that session.
The full-data coefficients are evaluated only on the three existing 200-target
matched panels, all disjoint from public targets.

## Results

| set | raw popularity | propensity | delta |
|---|---:|---:|---:|
| public, five-fold out of fold | 0.978500 | 0.978900 | +0.000400 |
| matched `20260830` | 0.979075 | 0.978675 | -0.000400 |
| matched `20260831` | 0.965725 | 0.965525 | -0.000200 |
| matched `20260901` | 0.961950 | 0.961950 | 0.000000 |

The out-of-fold arm preserves HR@10 1.0 and MRR 0.996667, changing only MTTC
from 2.025 to 2.005. The gain is one fiftieth of a turn per session and does not
clear the registered threshold. Two disjoint panels reverse its sign.

## Decision

Reject the propensity model and retain catalog `rating_number`, then stable
ASIN tie-break, as the only production ordering prior. The learned arm finds no
transferable headroom large enough to justify training, coefficient packaging,
or the additional public-label dependency. The harness remains as a falsifiable
record so the same hypothesis is not revived as an unmeasured ranking claim.

Reproduce with:

```text
python scripts/target_propensity.py --output .artifacts/experiments/exp-024.json
```
