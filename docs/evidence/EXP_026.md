# EXP-026 sentence-bounded disclosure parsing

Status: selected.

## Failure

The registered `filler` slice removed the target from one of 200 released sessions (`public_0020`). The inserted text followed a completed disclosure:

```text
A key requirement is: cotton., kind of
```

`SIGNATURE_MARKER_RE` intentionally accepts free-form values with `(.+)`, but the parser passed that entire capture into the category-bound key. It therefore changed the disclosed value from `cotton` to `cotton kind of`. The target remained at sparse rank 117--168 across later turns and never entered the emitted slate.

## Change

Bound a marker value at the first sentence terminator followed by whitespace, a comma, or end of input. Decimal points inside prices are not terminators. The same helper is used by exact-signature extraction, card-sequence parsing, and structured typo recovery so those paths cannot disagree on the disclosed span.

This is a structural parser invariant. It contains no filler vocabulary, released message string, product identifier, perturbation name, or public label.

## Results

On the registered seed-0 `filler` slice, target-removal rate falls from 0.005000 to 0.000000 and HR@10 returns from 0.995 to 1.000. The recovered session converts on turn 5 at rank 3, exactly as its unperturbed control. The other measured failures are unchanged: paraphrase 0.010000, typo 0.010000, and word order 0.012658 target removal.

An additional catalog-span recovery arm was tested and removed. It preserved clean score but did not improve any remaining aggregate gate, so its wider query surface did not earn production complexity.

## Decision

Select the shared sentence-boundary helper and its regression test. Do not describe it as general paraphrase or typo robustness; it closes one precisely reproduced parser failure.
